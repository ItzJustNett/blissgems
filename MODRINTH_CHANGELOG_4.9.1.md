# BlissGems v4.9.1 - Conduction Command

### ⚡ Flux Gem: Conduction is now a command
- **`/bliss conduction`** replaces the old **sneak + left-click** trigger. No more teleporting yourself mid-fight or mid-mine by accident.
- Only teleports to **copper blocks** — copper ore, deepslate copper ore, and raw copper blocks are ignored, so it can't drag you into a cave anymore.
- Tells you when there is **no copper within range** instead of silently doing nothing.
- Requires the Flux Gem as your active gem. Still uses `abilities.cooldowns.flux-conduction` and `abilities.flux-conduction.range` from `config.yml`.
- Gem lore updated to show the new command.
